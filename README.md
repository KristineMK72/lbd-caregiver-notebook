# LBD Caregiver Notebook

A personal caregiver notebook for Lewy Body Dementia.

Built around check-ins, medication timing, an ER handoff card, and plain-language guides.

**This is not a medical device and does not give medical advice.** Always follow your clinician’s instructions. In an emergency, call 911.

## Features

- Daily check-in (temperature, symptoms, notes)
- Medication list and dose clock with wearing-off awareness
- Reference notes on common LBD medications and drugs to avoid
- ER Card you can show staff
- Local storage only (data stays on this device)
